# CUA-Lark

CUA-Lark is a GUI agent for Feishu (Lark). It is designed to understand the visible interface, reason over multi-step tasks, and operate Feishu workflows through direct GUI interaction.

## What It Focuses On

- Navigating chats, docs, sheets, meetings, and other Feishu surfaces through the UI
- Understanding on-screen context and turning user goals into actionable steps
- Automating repetitive workflows that normally require manual reading, clicking, and switching between windows
- Acting as a practical computer-use agent for collaboration scenarios inside Feishu

## Example Scenarios

- Summarizing messages from a chat or group and extracting action items
- Opening related documents and gathering the information needed for a task
- Assisting with routine operations inside Feishu-based workflows
- Chaining multi-step tasks across different Feishu pages and windows

## Project Status

This repository is currently being initialized. The README describes the project direction; implementation details, code, and usage documentation will be added as the project evolves.

## Vision

The goal of CUA-Lark is to make Feishu a more programmable workspace through a GUI-native agent that can perceive, reason, and act in real user environments.
