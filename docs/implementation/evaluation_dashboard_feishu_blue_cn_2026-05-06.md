# Feishu Evaluation Dashboard Blue Chinese UI

Date: 2026-05-06

## Module Responsibility

Optimize the offline evaluation dashboard UI generated by
`build_evaluation_dashboard_html`. The dashboard remains a static review
artifact for evaluation summaries; it does not participate in the AgentS3
runtime loop.

## Design Direction

- Use `frontend-design` skill guidance with a clear product-console aesthetic:
  clean Feishu-aligned blue and white, dense but readable operational layout,
  restrained motion, and review-oriented hierarchy.
- Localize the dashboard homepage and primary controls into Chinese.
- Keep the page self-contained: plain HTML/CSS/JS emitted by Python, no network
  assets, no runtime server requirement.

## Boundaries

- In scope:
  - dashboard title, hero, metric cards, filters, score cards, section titles,
    table headers, empty states, and run details;
  - visual styling: blue/white palette, subtle grid, compact operational panels,
    accessible contrast, responsive layout.
- Out of scope:
  - no change to evaluation semantics;
  - no change to runtime report generation contracts except visible dashboard
    strings;
  - no deterministic Feishu execution path.

## Target Files

- `gui_agents/feishu/reports/evaluation_aggregator.py`
- `tests/feishu/reports/test_evaluation_aggregator.py`
- `docs/implementation/README.md`

## Manual Plan

- Target files: dashboard HTML generator and its tests.
- Depends on: existing `evaluation` JSON shape and current dashboard tests.
- Outputs: Chinese blue-white dashboard HTML with the same interactive filters
  and run-detail behavior.
- Verification:
  - targeted evaluation aggregator tests;
  - Black formatting check;
  - `python scripts/run_ci_checks.py`.
- Risks / rollback:
  - Large embedded HTML can be brittle. Mitigation: keep data/JS behavior
    names stable, update tests around visible text only.
  - Too much visual decoration could reduce scan efficiency. Mitigation: use
    compact 8px panels, table-first review layout, and restrained blue accents.
